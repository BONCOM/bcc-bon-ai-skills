# Why deferred

Broad session capture overlaps existing context and project-record mechanisms.

# Reconsider when

Repeated cross-session loss is measured and the missing information cannot be handled with scoped project notes or built-in history.

# Trust boundary

A memory plugin observes and persists conversation and tool context. Installation must account for retention, secrets, personal data, storage location, deletion, hooks, and any remote model or network processing.
