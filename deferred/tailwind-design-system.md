# Why deferred

It overlaps installed frontend and composition guidance and is specifically aimed at a Tailwind v4 design-system build.

# Reconsider when

A project is standardizing Tailwind v4 tokens, themes, component variants, dark mode, or a v3-to-v4 migration.

# Trust boundary

Guidance changes CSS architecture across the application and may add component dependencies. Confirm Tailwind major version and existing design tokens before applying it.
