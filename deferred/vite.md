# Why deferred

Framework-specific Vite guidance is unnecessary for repositories that do not use Vite.

# Reconsider when

A maintained project contains Vite configuration, plugins, SSR, library builds, or a Vite 8 migration.

# Trust boundary

The skill is generated reference content, but following it can change build configuration and plugin dependencies. Confirm the installed Vite version before applying migration advice.
